# VTR-PON3 導入・基本操作

VTR-PON3はWindows 11 x64向けの送出アプリです。画面には「VTR-PON」と表示されます。初回ベータは公開準備中です。公式ダウンロードページに公開版が掲載されるまでは、開発用ビルドや候補パッケージを配布版として使用しないでください。

## 動作条件

- Windows 11 x64。フルスクリーンのオンエア出力には2画面構成を推奨します。2画面目がない場合は主画面に出力します。
- インストーラーはユーザー単位で導入します。仮想カメラの登録・更新・削除にはWindowsの管理者権限とUACの許可が必要です。ZIP版は展開して起動できますが、仮想カメラを自動登録しません。
- 本体の主な入力は動画・音声ファイル、PNG／JPEGなどの静止画、PDF、PowerPoint、UVCカメラ、内蔵テストパターンです。拡張子だけで再生を保証するものではありません。実際に使うコーデック、解像度、音声、カメラを事前に確認してください。
- PowerPointのネイティブ再生にはMicrosoft PowerPointが必要です。文書の変換方式によっては準備に時間がかかります。
- Roland V-8HD連携、UVC、仮想カメラ、返しモニターは対応機器とWindows側の設定に依存します。

## 導入と更新

1. 公開後は公式Windows版ダウンロードページ `https://pondashi.com/vtr-pon/download/windows/` からインストーラー版かZIP版を取得し、掲載されたSHA-256を照合します。現時点では公開版の掲載を確認していません。
2. インストーラー版はVTR-PONと関連する補助プロセスを終了してから実行します。本体はユーザー単位で導入され、仮想カメラの変更時はUACの確認が出ます。スタートメニューからVTR-PONを起動します。
3. ZIP版は全ファイルを任意のフォルダーへ展開し、その中の`vtr-pon.exe`を起動します。ZIP内から直接起動しないでください。スタートメニューへの登録と仮想カメラの自動登録は行いません。設定は通常 `%APPDATA%\VTR-PON3\user.ini` に保存され、設定も持ち運べる形式ではありません。
4. 初回送出前に、オンエアの表示先、音声出力先、素材の再生、保存・復元を実機で確かめてください。
5. 更新前には重要な設定とプレイリストをバックアップしてください。インストーラー版は新しいインストーラーを実行します。ZIP版は新しいZIPを別フォルダーへ展開し、確認後に古いフォルダーを削除します。どちらも通常の設定、ログ、キャッシュ、生成素材は自動削除されません。

## 最初の操作

1. `Ctrl+F` で素材をプレイリストに追加します。オフライン表示の素材は元ファイルや機器の接続を確認してください。
2. 項目を選び、`E` でエディットに読み込んで内容を確認します。必要ならIN／OUT点やPFLを調整します。
3. `Enter` で選択項目をオンエアにします。再生開始か一時停止かは項目のStart Modeに従います。切り替え方はクロスフェードの設定に従います。OFFなら即座に切り替わり、ONなら指定した秒数で徐々に切り替わります。
4. `Space` でオンエアの再生／一時停止、`Esc` でオフエアにします。プレイリストは画面の保存・復元操作で管理します。キー割り当ては設定で変更できます。

## VTR-PON2との関係とアドオン

VTR-PON3はVTR-PON2とは別製品です。VTR-PON2の設定とプレイリストの移行・読み込みには対応しません。必要な素材や運用手順は新しいプレイリストで準備してください。

初回ベータにはアドオンを同梱しません。ATEM連携、NDI入出力、VST3音声エフェクトは対応版と導入手順が整ってから別配布します。公開前の開発用パッケージは導入しないでください。

## 現在の制約・既知の問題

- すべての素材形式、コーデック、UVC機器、表示環境での動作は保証できません。素材や接続機器ごとにリハーサルしてください。
- PDF／PowerPointのネイティブ送出では通常の動画用PLAY／PAUSEやシークではなく、文書用の前／次操作を使います。変換中の項目は完了を待ってからオンエアにしてください。
- 仮想カメラ、実映像・物理音声、別PCでの導入・削除は公開前の最終確認が残っています。結果に応じてこの案内を更新します。
- VTR-PON2からの移行と初回ベータでのATEM・NDI・VST3アドオン利用には対応しません。
