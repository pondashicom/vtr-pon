ATEM・NDI・VST3・DeckLink は本体と別配布する。初回の本体 3.0.0-beta.1 と同時に、それぞれ 0.3.0 を別配布する。本体配布物には、各アドオンとその SDK／ベンダー Runtime を含めない。アドオンの自作部分は MIT、SDK 由来部分や依存ライブラリには各権利者の条件を適用し、各パッケージの文書で範囲を案内する。

VTR-PON3公式アドオン案内で対応版と必要ソフトを確認し、本体の「設定 → アドオン」から導入する。導入時には、パッケージに収録された利用条件・通知を確認して同意する。各0.3.0のソース・MIT本文・版固有の配布条件は、次のリポジトリで案内する。

DeckLink アドオンの利用には、Blackmagic Design 公式の Desktop Video Windows x64 版を別途インストールする。現行実装は Desktop Video API 16.0 以上を要求する。DeckLink SDK はアドオンの開発時だけ必要で、本体のビルドと通常の利用には不要。本体やアドオンの導入・削除は、Desktop Video の導入・削除を代行しない。

DeckLink アドオンの自作コードと MIT 本文は独立リポジトリで管理する。公開する各パッケージに記載された対応本体版、Desktop Video の検証版、ライセンス・通知を確認する。Blackmagic Design および DeckLink の名称・商標は各権利者に帰属する。

Qt、GStreamer 等の共有ライブラリを使用します。互換の改変版への交換、およびその改変のデバッグに必要なリバースエンジニアリングを VTR-PON の条件で制限しません。アプリを終了してから、Qt は EXE 横と各プラグインディレクトリ、GStreamer は gstreamer/bin と gstreamer/lib/gstreamer-1.0 の DLL を交換してください。
