# Test Patterns

VTR-PON2の素材は使用せず、この作業で生成した13素材を管理する。
このディレクトリの自作素材・生成元・プレビューは[CC0 1.0](../../LICENSE/CC0-1.0.txt)で提供する。第三者の規格、商標、フォント、コーデックの権利は含まない。

- `media/`: 配布・再生用の動画／音声。英語ファイル名を日英共通のメニュー表示名に使用する。
- `catalog.json`: 同梱素材の初期表示順。カラーバー、チェッカー、グリッド、アスペクト比、カウントダウン、動き、フレーム番号、透過マーカー、音声の順。
- `previews/`: 確認用画像。配布しない。
- `sources/`: 描画スクリプト・フィルター・元画像・生成記録。配布しない。

`vtr-pon`の通常ビルドで`media/`と`catalog.json`を実行ファイル横の
`assets/testpatterns/`へコピーする。ライセンス本文は実行ファイル横の
`LICENSE/`へコピーする。配布時もこの相対配置を維持する。

## 設定と操作

「設定 → テストパターン」で登録・一覧からの削除・上下移動ができる。
変更は即時保存され、「ツール → テストパターン」に反映される。
一覧が空の場合も保存される。「同梱素材を一覧に戻す」は除外した同梱素材を末尾に戻す。

ユーザー素材は元ファイルへのパス参照で登録する。ファイルのコピーや物理削除はしない。
同じ実体の二重登録を防ぎ、別フォルダーの同名素材は登録できる。
選択した素材のフルパスは設定ページに表示し、メニューのツールチップにも設定する。
動画・PNG/JPEG静止画・音声を登録できる。再生可否は既存の素材追加時解析に従う。

メニュー選択で現在のプレイリストへ通常ITEMとして追加する。静止画の表示時間設定なども
通常の素材追加と共通。追加だけでON AIRにはしない。元ファイルの欠損・解析失敗は既存のInfo-barで通知する。
同梱素材一覧から削除しても、元ファイルや登録済みプレイリストITEMには影響しない。

一覧設定はローカルの`testPatterns/entries`に保存する。同梱素材はファイル名IDから
現在の実行ファイル位置へ解決し、ユーザー素材は絶対パスで参照する。
既存の設定ファイルのエクスポート／インポートにはこのローカル素材一覧を含めない。
プレイリスト自体は従来どおり絶対パス保存なので、アプリや素材を移動した場合は再登録が必要。

## 素材仕様

- 16:9映像: 1920×1080、30fps。4:3映像: 1440×1080、30fps、正方画素。
- 通常素材は20秒、カウントダウンは20〜0を各1秒表示する21秒。
- 動き付きカラーバーとフレーム番号チェッカーは180秒。
- カラーバー／チェッカー／動き付きカラーバーは1kHz音声付き。その他の映像は無音。
- 音声WAVは48kHz／24bit／左右同相ステレオ／20秒。
- 1kHzピーク−18dBFS。ピンク・ホワイトノイズはRMS約−21dBFS。
- Safety AreaはVP9アルファ付きWebM。90%／80%枠と内側のピクセルルーラー。
  ファイルのアルファは確認済み。VTR-PONの実機透過合成は未確認。

細かな信号値・生成レシピは`sources/GENERATION_NOTES.md`参照。
記録内の旧「未実装」の記載は生成時点の履歴であり、現在のメニュー対応状況は本READMEが優先する。
再生成コマンドの素材入出力は`media/`、PNG／filter／Pythonは`sources/`へパスを合わせる。
