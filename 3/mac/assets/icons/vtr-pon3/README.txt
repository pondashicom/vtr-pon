VTR-PON3 Icon Set - Stage Bottom
================================

Approved design:
- A large centered play symbol
- A trapezoidal stage at the bottom
- A dark blue-gray rounded-square background
- Orange carried over from VTR-PON2

The PNG, ICO, and ICNS files were derived from the approved raster image.
The SVG is an editable vector reconstruction. Its shading may differ slightly
from the raster files.

windows/VTR-PON3.ico
  Windows executable and installer icon. Contains 16, 20, 24, 32, 40, 48,
  64, 128, and 256 pixel images.

windows/png/
  PNG sizes used by the Qt application window icon.

mac/VTR-PON3.icns and mac/VTR-PON3.iconset/
  macOS icon and source PNG files.

master/
  Editable SVG and approved high-resolution raster references.
