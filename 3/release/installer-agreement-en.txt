USAGE NOTICE
When enabled, VTR-PON sends its version to pondashi.com during automatic or manual update checks, at most once per UTC day. It sends no installation ID or media information. The activity database stores only daily counts by version; the web host may retain standard access logs.

The notice is enabled for a new installation after you accept. If you previously turned it off, an update preserves that choice. You can turn the notice off later in Settings > Updates and notices. Automatic update checks can be turned off separately on the same page. Manual update checks remain available.
